# Engineering Portfolio

This folder is ready to upload to a GitHub Pages repository.

## Before uploading

Open `index.html` and replace:

- `DJ [Last Name]` with your full name.
- `YOUR_EMAIL@example.com` with your email address.
- `YOUR-LINKEDIN` with your LinkedIn profile slug/link.
- `YOURUSERNAME` with your GitHub username.
- Rename your résumé PDF to `DJ_LastName_Resume.pdf` or change the link in `index.html`.

## Publish on GitHub Pages

1. Create a public repository named `YOURUSERNAME.github.io`.
2. Upload `index.html`, `styles.css`, and your résumé PDF to the root of that repository.
3. Open the repository's **Settings > Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`.
6. Save.

Your site will be available at:

`https://YOURUSERNAME.github.io`

## Adding project photos later

The current version intentionally works without photos so you can publish quickly.

A good next step is to add 1–2 strong photos for each major project:
- Senior design agitator / enclosure
- Snap-on control panel or approved machine image
- Bonnell CAD drawing or approved project image
- PLC/HMI screenshot

Avoid uploading confidential company drawings, controls code, internal machine data, or photos you were not permitted to share.
